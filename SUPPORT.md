# Support

This is a community-maintained development project, not a commercial service.
Support is best-effort and does not include recovery guarantees for unbacked-up
vaults.

Before requesting help:

1. Back up the vault outside Syncthing.
2. Read the
   [Windows to iPad to Obsidian guide](docs/WINDOWS_TO_IPAD_AND_OBSIDIAN.md).
3. Check [current status and limitations](STATUS.md).
4. Search existing GitHub Issues.
5. Reproduce with disposable data when possible.

Open a bug report for reproducible project behavior or a feature request for a
scoped proposal. Follow [SECURITY.md](SECURITY.md) instead of using a public
issue for vulnerabilities, secrets, or potentially exploitable data exposure.

Never post Apple credentials, two-factor codes, signing material, complete
Syncthing device IDs, private network addresses, real vault contents, or
unredacted reports.
